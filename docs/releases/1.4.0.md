# Figlets 1.4.0

Published November 8, 2026: [Figlets 1.4.0](https://github.com/arashr/figlets-mcp/releases/tag/v1.4.0). Release commit: 62a557a.

Scope: changes since v1.3.0, including the committed checkpoints through c013b82 and the font-fallback, cleanup, and release-preparation changes.

## Designer experience

- Clearer, shorter outputs with visual hierarchy and appropriate choice controls when the host supports them.
- Optional motion is asked during normal intake and included in the same setup preview and build.
- Contrast warnings no longer trap designers in repeated fixes. Icon-only findings are advisory, and an explicit decision to continue is honored. Semantic repairs use existing primitive steps.
- Component QA skips component-set container properties and inactive Auto gaps while retaining variant and nested-layer checks.
- Raw primitive values are valid inventory. Imported systems are not flagged for unchosen typography or elevation defaults, and Figlets handles missing internal setup information itself.
- A confirmed design-system name survives refresh. The 44px AAA touch-target recommendation remains guidance rather than an export blocker.

## Correct output

- Requested 0-100 color ramps now produce the requested steps. Brand colors remain exact, and default main brand surfaces use their actual anchors in both modes.
- Optional display fonts remain distinct from body and UI fonts through setup and generation.
- Scrims appear at the end of Primitive Colors, with a single inset overlay over a contrasting neutral background.
- Missing fonts use verified fallbacks in generated documentation and showcases. Available fonts retain their existing behavior. Source fonts and bindings are not rewritten.
- Markdown handoffs still complete when visual documentation fails. Results distinguish partial completion and prevent unchanged retry loops. Existing spec sheets remain until replacements render successfully.
- DESIGN.md follows Google's 0.4.0 format, with an optional companion file for exact Figlets data. Modern motion, opacity, and composed colors retain useful values in documentation, CSS, and Make guidance.
- Component documentation resolves nested library aliases and reports more complete paint, effect, and token information. Motion timeline inspection is still outside its verified scope.
- Variable-value updates validate before writing and attempt rollback after a failure. Results distinguish changed, unchanged, blocked, rolled-back, and uncertain outcomes. Structural updates do not share the same rollback guarantee.

## Unchanged

Native Figma Specs replacement is shelved. The current in-Figma documentation sheet, component Markdown, descriptions, DESIGN.md, and Bridge-only integration remain.
